# Revisão – Segurança em Sistemas de Informação

Questionário estático com 20 questões, justificativas obrigatórias, correção automática, nota de 0 a 10, gabarito comentado e exportação de resultado em TXT.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub, por exemplo `revisao-seguranca`.
2. Envie o arquivo `index.html` para a raiz do repositório (o README é opcional).
3. Acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**, branch **main**, pasta **/(root)** e salve.
5. Após a publicação, o endereço geralmente será `https://SEU-USUARIO.github.io/revisao-seguranca/`.

## Limitações

- As respostas são corrigidas localmente no navegador.
- O GitHub Pages não armazena nem envia respostas dos alunos ao professor.
- O aluno deve baixar o TXT e enviá-lo pelo canal definido pelo professor.
- A nota considera somente as alternativas (0,5 ponto por acerto); justificativas precisam de avaliação humana.
- O gabarito está no código JavaScript, portanto pode ser inspecionado antes da finalização. Não use este site como prova sigilosa.
- Os arquivos TXT podem ser editados; não servem como comprovação inviolável de autoria ou nota.
